# Lux agent contract

- Read the relevant source and tests before editing.
- Keep changes inside the repository and never run destructive commands without explicit approval.
- Treat dependency installation, network access, commits, pushes, and production actions as approval-gated.
- Validate paths with resolved paths before reading or writing artifacts.
- Run the smallest relevant test suite plus linting before declaring success.
- Report changed files, verification results, and any unverified assumptions.
